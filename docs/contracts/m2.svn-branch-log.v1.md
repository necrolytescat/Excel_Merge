# `m2.svn-branch-log.v1` 分支提交 LOG 契约

> 状态：已实施
> 版本：`m2.svn-branch-log.v1`
> 日期：2026-08-12

## 1. 用途与边界

`GET /api/svn/branch-logs` 为版本对比 1A 端点卡片提供当前分支的历史提交选择。
它是只读、分支级、游标分页接口，不复用会读取宽 Revision 范围的
`GET /api/svn/log`。

- 查询目标只能是用户当前选择的分支 URL，不得替换为仓库根 URL。
- 提交按 Revision 严格降序返回，并通过 SVN `--stop-on-copy` 在分支创建点停止。
- 响应只暴露 Revision、提交人、提交时间和 Message，不返回 changed paths。
- HEAD 是页面固定选项，不属于 `commits[]`，也不计入分页条数。

## 2. 请求

```http
GET /api/svn/branch-logs?url=https%3A%2F%2Fsvn.example%2Frepo%2Fbranches%2Ffix&limit=30
```

| 参数 | 必填 | 规则 |
|---|---:|---|
| `url` | 是 | 当前所选分支 URL；沿用 SVN URL 与协议校验 |
| `limit` | 否 | 正整数 1..100，默认 30 |
| `cursor` | 否 | 上一页返回的 opaque base64url 游标，最长 512 字符 |

客户端不得解析、修改或跨 URL 复用游标。切换分支后必须丢弃旧游标与已加载提交。

## 3. 响应

```json
{
  "schema_version": "m2.svn-branch-log.v1",
  "commits": [
    {
      "revision": 26476,
      "author": "designer.a",
      "date": "2026-08-12T05:30:00Z",
      "message": "调整活动配置"
    }
  ],
  "next_cursor": "eyJyZXZpc2lvbiI6MjY0NDYsInVybCI6Ii4uLiIsInYiOjF9",
  "has_more": true
}
```

| 字段 | 规则 |
|---|---|
| `schema_version` | 固定 `m2.svn-branch-log.v1` |
| `commits[]` | 最多 `limit` 条；Revision 降序且页内唯一 |
| `commits[].revision` | 严格正整数 |
| `commits[].author` | 字符串；SVN 未提供时为空字符串 |
| `commits[].date` | SVN 提交时间字符串；通常为 UTC ISO 8601，未提供时为空字符串 |
| `commits[].message` | 字符串；SVN 未提供时为空字符串 |
| `next_cursor` | 有下一页时为 opaque 字符串，否则为 `null` |
| `has_more` | 是否仍有下一页；为 `false` 时 `next_cursor` 必须为 `null` |

服务端向 Provider 请求 `limit + 1` 条，仅用额外一条判断下一页并生成 Revision
边界。CLI 固定使用：

```text
svn log --xml --stop-on-copy --limit <limit+1> <selected-branch-url>
```

首屏由 SVN CLI 对 URL 默认使用 `HEAD:1`；后续页增加
`--revision <cursor-revision>:1`。服务端不得先读取整个仓库历史再分页。

## 4. 游标与错误

游标以 base64url 编码版本、规范化 URL 的 SHA-256 和下一页 Revision 边界。
编码结构是服务端实现细节，不构成客户端字段契约。

| HTTP | 错误码 | 条件 |
|---:|---|---|
| 400 | `SVN_INVALID_CURSOR` | 游标损坏、字段非法或跨分支 URL 复用 |
| 400 | `SVN_NOT_FOUND` / `SVN_AUTH_FAILED` | URL 无效、分支不存在或无权限 |
| 400 | `SVN_HISTORY_UNAVAILABLE` | 当前 Provider 不支持分支历史 |
| 422 | FastAPI 参数错误 | `limit` 或参数长度越界 |

错误响应沿用 `{"error":{"code":"...","message":"..."}}`。失败不影响页面继续使用
固定 HEAD 选项；客户端应保留已加载提交并提供原位重试。

## 5. 验收

- 首屏恰好最多 30 条，第二页追加后无重复，末页关闭“加载更多”。
- 损坏游标和跨分支游标返回 `SVN_INVALID_CURSOR`。
- CLI 使用所选分支 URL、倒序范围、`--stop-on-copy` 和 `limit + 1`。
- FIX 分支不返回 copy 来源中早于创建点的提交。
- JSON 每条提交只含 `revision/author/date/message`。
- 滚动到列表底部自动加载下一页，失败时停止自动请求并保留原位重试。
