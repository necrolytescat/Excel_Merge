# `m2.batch-management.v1` 任务管理契约

> 状态：P2 采用
> 日期：2026-08-09

## 1. 目标

该契约为“历史任务”提供结构化任务事件、正式结果统计和重试关系，不修改 `m2.batch.v1`，不复制 `m2.diff.v1` 明细，也不暴露内部结果路径、SVN URL、凭据或异常堆栈。

## 2. 管理详情

```text
GET /api/diff/batches/{task_id}/management
```

响应支持 ETag/304：

```json
{
  "schema_version": "m2.batch-management.v1",
  "task_id": "00000000-0000-4000-8000-000000000001",
  "status": "completed",
  "retry_of_task_id": null,
  "retry_child_task_ids": [],
  "results": {
    "count": 2,
    "size_bytes": 4096,
    "expires_at": "2026-09-08T01:00:00Z"
  },
  "events": [
    {
      "event_id": 1,
      "event_type": "task.created",
      "level": "info",
      "message": "任务已创建",
      "details": {"status": "queued"},
      "created_at": "2026-08-09T01:00:00Z"
    }
  ],
  "can_delete": true
}
```

`results.count` 只统计已发布 `result_ref` 的正式结果，`size_bytes` 使用未压缩规范 JSON 字节数。旧任务没有事件记录时，服务端只允许从任务权威时间戳补充“创建”和当前终态基线事件。

## 3. 结构化事件

事件独立存储，不写入 `m2.batch.v1`。当前记录：

- 创建、准备、运行和终态状态转换；
- 取消、重试创建和手动删除命令；
- 可公开的任务/单项错误码与消息；
- 服务重启后的准备或租约恢复。

`details` 仅允许字符串、整数、布尔或 null，不返回结果路径、原始日志、SVN 地址、凭据、请求堆栈或 Diff 明细。默认保留 90 天，可通过 `batch_diff.event_retention_days` 独立配置；它不随正式结果文件直接删除。

## 4. 手动删除

```text
DELETE /api/diff/batches/{task_id}
```

请求：

```json
{
  "schema_version": "m2.batch-delete.request.v1",
  "request_id": "00000000-0000-4000-8000-000000000002",
  "reason": "history cleanup"
}
```

`request_id` 提供严格幂等；同一请求重放返回相同结果，用于不同命令时返回 409 `BATCH_IDEMPOTENCY_CONFLICT`。

响应：

```json
{
  "schema_version": "m2.batch-delete.result.v1",
  "task_id": "00000000-0000-4000-8000-000000000001",
  "deleted_at": "2026-08-09T02:00:00Z",
  "deleted_result_count": 2,
  "deleted_result_size_bytes": 4096,
  "tombstone_expires_at": "2026-08-16T02:00:00Z"
}
```

仅终态任务可删除；活动任务返回 409 `BATCH_TASK_NOT_DELETABLE`。删除后任务立即从列表消失，按 ID 查询返回 410 `BATCH_TASK_DELETED`，结果引用返回 410；墓碑期结束后返回 404。

## 5. 生命周期与边界

- 删除只物理清理该任务 `results/<task_id>/` 下的正式 gzip 结果；正式结果是任务产物，不是缓存。
- 父任务与重试子任务独立删除，不级联。
- 结构化事件按独立保留期清理。
- 原始应用日志由日志轮转管理，不随任务删除。
- SVN 缓存是跨任务共享的全局可再生数据，任务 API 不得删除或按任务归属处理。
- Replay `.m2fixture` 是版本化回归资产，不进入任务删除或自动清理。
