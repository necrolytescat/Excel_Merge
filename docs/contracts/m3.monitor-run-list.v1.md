# m3.monitor-run-list.v1 版本监控运行列表契约

> 状态：Phase 5 冻结
> Schema：app/schemas/monitor.py::MonitorRunListPayload

items 严格复用 m3.monitor-run.v1，按 logical_cutoff_at DESC, run_id DESC 稳定排序。limit 为 1..100；next_cursor 是绑定 task ID 与规范筛选的 base64url 不透明游标，跨任务或篡改返回 400 MONITOR_INVALID_CURSOR。

ETag 对排除顶层 as_of 的规范 JSON 投影计算。服务端发强标签，If-None-Match 的同值强/弱标签均可返回 304。
