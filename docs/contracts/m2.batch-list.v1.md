# `m2.batch-list.v1` 历史任务列表契约

> 状态：P1 采用
> 日期：2026-08-09

## 1. 路由

```text
GET /api/diff/batches
```

该接口只返回当前所有者范围内、尚未过期的任务摘要，不替代 `GET /api/diff/batches/{task_id}`，也不改变 `m2.batch.v1`。

## 2. 查询参数

| 参数 | 规则 |
|---|---|
| `limit` | 默认 20，范围 1..100 |
| `cursor` | 可选，不透明游标；仅用于继续当前排序 |
| `status` | 可重复的 `m2.batch.v1` 任务状态 |
| `q` | 可选，最长 128；匹配 Task ID 前缀或端点 ID |
| `created_from` | 可选，UTC RFC 3339，创建时间下界（含） |
| `created_to` | 可选，UTC RFC 3339，创建时间上界（含） |

固定排序为 `created_at DESC, task_id DESC`。游标非法返回 HTTP 400 `BATCH_INVALID_CURSOR`；时间范围反向返回 HTTP 400 `BATCH_INVALID_TIME_RANGE`。

## 3. 响应

```json
{
  "schema_version": "m2.batch-list.v1",
  "items": [
    {
      "task_id": "00000000-0000-4000-8000-000000000001",
      "retry_of_task_id": null,
      "status": "running",
      "source": {"endpoint_id": "LEFT", "revision": 101},
      "target": {"endpoint_id": "RIGHT", "revision": 202},
      "progress": {
        "total_items": 10,
        "queued_items": 4,
        "running_items": 1,
        "succeeded_items": 5,
        "business_failed_items": 0,
        "orchestration_failed_items": 0,
        "skipped_items": 0,
        "cancelled_items": 0,
        "processed_items": 5,
        "ratio": 0.5
      },
      "task_error_count": 0,
      "created_at": "2026-08-09T01:00:00Z",
      "updated_at": "2026-08-09T01:01:00Z",
      "finished_at": null,
      "expires_at": null
    }
  ],
  "next_cursor": null,
  "has_more": false,
  "as_of": "2026-08-09T01:01:01Z"

```

每一级对象严格拒绝未知字段。`progress` 复用 `m2.batch.v1` 的计算口径；候选未准备完成时 `total_items/ratio=null` 且其他计数为 0。

## 4. 安全与保留

- 所有者范围由服务端决定，不接受客户端提交。
- 列表不返回 `request_id`、完整单项、`result_ref`、结果路径、SVN URL、凭据或错误堆栈。
- 终态任务在 `expires_at` 到达后立即从列表消失；按 ID 查询返回 410。
- 活动任务没有 `expires_at`，不按创建时间自动清理。
- 支持 ETag；匹配 `If-None-Match` 时返回 304。
