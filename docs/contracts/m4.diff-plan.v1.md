# `m4.diff-plan.v1` 计划管理契约

> 状态：阶段一、二实现契约  
> 日期：2026-08-12

## 计划定义

```json
{
  "schema_version": "m4.diff-plan.v1",
  "plan_id": "00000000-0000-4000-8000-000000000001",
  "name": "战斗数值核心表",
  "source_endpoint_id": "Trunk_TC",
  "target_endpoint_ids": ["TC_Fix", "KR_Fix"],
  "workbook_paths": ["Battle/Hero.xlsx", "Battle/Skill.xlsm"],
  "version": 1,
  "archived": false,
  "created_at": "2026-08-12T08:00:00Z",
  "updated_at": "2026-08-12T08:00:00Z",
  "archived_at": null,
  "recent_run": null
}
```

规则：计划名称 1～128 字符；目标分支 1～4 个且唯一；工作簿 1～10 张，使用 TABLE 相对路径且大小写不敏感唯一；基准分支不得出现在目标分支中。所有模型拒绝未知字段。

## 写命令

- 创建：`m4.diff-plan-create.request.v1`，包含 UUID `request_id` 和完整定义。
- 更新：`m4.diff-plan-update.request.v1`，额外包含正整数 `expected_version`。
- 归档/恢复：`m4.diff-plan-command.request.v1`，包含 `request_id` 和 `expected_version`。

相同 `request_id` 与相同规范输入返回原结果；不同输入返回 409 `DIFF_PLAN_IDEMPOTENCY_CONFLICT`。版本不匹配返回 409 `DIFF_PLAN_VERSION_CONFLICT`。

## TABLE 目录

`m4.workbook-catalog.request.v1` 接受端点 ID 和 `HEAD` 或正整数 Revision。响应 `m4.workbook-catalog.v1` 返回冻结 `resolved_revision`、TABLE 物理路径以及相对 TABLE 根的 Excel 清单。扩展名仅限 `.xlsx/.xlsm/.xls`。
