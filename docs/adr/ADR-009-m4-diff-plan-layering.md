# ADR-009：M4 使用独立计划编排层复用 M2 语义能力

> 状态：已接受  
> 日期：2026-08-12

## 决定

M4 不扩展或绕过 `m2.batch.v1`。M4 新建独立计划、运行和矩阵契约，只对计划选中的 TABLE 工作簿执行；单工作簿语义结果继续使用 `m2.diff.v1`。

## 理由

`m2.batch.v1` 的输入只有一个冻结端点对，并由服务端重建完整差异候选集。M4 需要表达固定路径子集和最多四个目标分支，直接修改 M2 会破坏已冻结契约；创建多个完整 M2 批次又会读取并执行未勾选表格。

## 后果

- M4 需要独立状态机、存储和多分支结果汇总。
- M2 的 source/target、同 Revision 配对、TableCsv 和业务语义保持唯一事实来源。
- M4 结果引用直接返回原始 `m2.diff.v1`，不得复制或重写明细 JSON。
