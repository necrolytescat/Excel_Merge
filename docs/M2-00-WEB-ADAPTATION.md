# M2-00：Web 前端适配

> 状态：待执行  
> 目标：将现有 M1“版本对比”页面适配为可承载单文件 Excel 语义 Diff 的工作台，同时保留已验证的 SVN 输入和快照流程。

## 1. 范围

M2-00 只调整页面布局、信息层级、导航关系和页面状态，不实现 Excel 解析、Sheet/行/单元格 Diff，也不改变 M1 快照接口。

本阶段完成后，用户应能理解并顺畅完成两条入口：

1. 正式入口：选择两个 SVN 端点，冻结快照，从文件级候选进入单文件 Diff；
2. 开发验证入口：选择同一工作簿的 old/new 本地样本，验证后续语义引擎。

开发验证入口使用独立页面 `/compare/demo`，只在开发模式开放，不在正式 `/compare` 页面显示入口，也不进入正式生产导航。该页面只使用明确标注的 UI 假数据，不读取本地工作簿。

### 已冻结区域

- `1A 确认两个端点并生成快照` 已冻结；除非产品负责人明确允许，不再修改其布局、信息结构、控件和页面状态。
- 正式 Diff 工作台不提供本地文件上传或“载入流程示例”入口。

## 2. 信息架构

页面维持大宽度工作区，按任务进程拆分为两个可深链接页面：

```text
顶部任务导航
├─ /compare：版本与快照
│  ├─ A. 版本输入与快照
│  └─ B. 文件级差异候选 + 执行差异比对
└─ /compare/results：差异结果
   ├─ 工作簿导航与单工作簿操作
   ├─ Sheet 导航
   ├─ 行/单元格差异主视区
   └─ 当前差异详情
```

### A. 版本输入与快照

- 沿用 M1 的左右端点搜索、交换和“锁定并读取快照”；
- 沿用快照状态中的阶段进度、耗时和错误信息；
- 快照 ready 后突出显示差异候选数量和进入候选清单的操作；
- 不重新引入日期或手工 Revision 输入。

### B. 文件级差异候选

- 版本与快照页使用已由 Demo 验证的桌面可读字号，并与正式页面保持一致；
- 沿用 M1 以逻辑相对路径匹配的文件级候选；
- 展示状态、相对路径、文件元信息和解析状态；
- 候选清单只展示本次需要处理的全部文件级差异，不承担单工作簿结果导航；
- 在候选标题区使用唯一主操作“执行差异比对（N）”，固定处理全部候选并进入独立结果页；
- 仅左/仅右文件允许进入工作台，并由后续引擎显示 file_added/file_deleted 状态。

### C. 独立差异结果页

- `WORKBOOK DIFF RESULTS` 使用已由 Demo 验证的桌面布局与字号，并与正式结果页保持一致；
- 结果页使用独立路由，不与端点、快照和候选输入纵向堆叠；
- 页面顶部任务栏只展示左侧分支名、右侧分支名和文件级差异数量；
- 当前工作簿的 old/new 文件名、来源端点和冻结 Revision 放在工作台文件上下文中；
- 左侧先展示工作簿结果导航，再展示 Sheet 状态和差异数；
- 中部为大宽度差异表格，按业务主键组织行；
- 右侧为可收起的单元格详情，展示字段、旧值、新值和定位信息；
- “比对当前工作簿”或重试操作只出现在结果页，不在候选输入页提供；
- 大表使用分批渲染或虚拟列表，切换 Sheet 不改变外层布局尺寸。

## 3. 页面状态

| 状态 | 页面行为 |
|---|---|
| `idle` | 显示端点输入；候选和工作台为空态 |
| `snapshot_loading` | 进度只显示在快照状态中，输入和确认操作锁定 |
| `snapshot_error` | 快照区域显示可定位的错误，保留端点选择以便重试 |
| `candidates_ready` | 展示文件级候选，工作台提示选择一个文件 |
| `diff_loading` | 工作台保留文件上下文并显示解析/Diff 进度 |
| `diff_empty` | 明确显示已完成且无语义差异，不与未执行混淆 |
| `diff_error` | 显示失败阶段和文件，不把失败降级为空差异 |
| `diff_ready` | 展示 Sheet、行和单元格差异 |

## 4. 交互约束

- 端点输入和快照过程继续遵守 M1 契约；
- 候选列表可搜索和按文件状态筛选，分支较多时不使用超长下拉框；
- 当前选中文件和 Sheet 必须有稳定、高对比度的选中态；
- 差异颜色同时配合文字或图标，不仅依赖颜色表达状态；
- 空态、加载态、失败态和无差异态必须明确区分；
- 页面在常见桌面宽度下优先保证差异表格空间，窄屏允许详情区收起或下移；
- 不在卡片中继续嵌套卡片，区域通过边框、背景层级和分栏区分。

## 5. M2-00 不做

- 不定义未经样本验证的业务主键自动推断规则；
- 不实现或伪造 Sheet、行、单元格差异；
- 不让前端直接读取 SVN 或完整工作簿二进制；
- 不改动 M1 的端点注册、HEAD 冻结、物理路径绑定和文件级候选算法；
- 不实现 Merge、Excel 写回或 SVN 写操作。

## 6. 验收标准

- 页面保留 M1 已验证的端点选择、快照进度和文件级候选能力；
- 用户从候选页执行全部差异比对后进入独立结果页；
- 工作台具备文件上下文、Sheet 导航、差异主视区和详情区；
- 八种页面状态都有独立、可识别的展示方式；
- 工作台在没有语义引擎数据时使用明确空态，不展示伪造结果；
- 桌面大宽度布局下候选清单和差异表格无不必要横向压缩；
- M1 API 和 114 项回归测试保持通过。

## 7. 后续衔接

M2-01 选择同一 Excel 工作簿的 old/new 两个版本作为首组样本。M2-02 至 M2-04 完成独立语义引擎，M2-05 将真实结果接入本工作台；M2-06 最后接入 M1 已冻结的 SVN 候选内容。
