# 验收用例

> M1 验收结论：通过并归档（2026-08-05），全量测试 114 passed，真实 KR FIX 文件级差异候选为 53。

## 1. M0 SVN 只读基座

### AC-M0-01 基础连接

- 输入合法 SVN URL，页面显示仓库根地址、UUID、HEAD/最近变更 Revision、作者和时间；
- URL 含账号或密码时拒绝保存；
- 认证失败、超时、路径不存在和 CLI 不可用返回稳定错误码。

### AC-M0-02 目录树和内容

- 目录树支持递归列举和安全相对路径；
- `..` 路径被拒绝；
- 内容读取保留中文编码和截断标记；
- Provider 只执行 `info/list/cat` 等 SVN 只读命令。

## 2. M1 版本对比快照

### AC-M1-01 页面范围

打开 `/compare`：

- 导航名称为“版本对比”；
- 存在左侧端点、右侧端点和“锁定并读取快照”；
- 页面只展示 `Table` 和“全量 Excel”；
- 不存在日期选择、手工 Revision 输入、`CONFIG`、`TABLECSV` 或 CSV 文件清单；
- 文件清单列为相对路径、最后修改人、修改时间、版本号；
- 页面保持大宽度布局。

### AC-M1-02 端点注册表

输入两个具体记录 `KR_FIX_1_1_0` 和 `KR_FIX_1_0_0`：

- 两条记录可以同时保存；
- ID 重复、非法 URL、路径穿越和未知逻辑目录被拒绝；
- `logical_scopes` 输入大小写可兼容，持久化后统一为 `TABLE`；
- disabled 端点不能创建快照。

### AC-M1-03 Table 物理路径发现

给定 `Resource/table`、`resource/Table` 或带上层目录的真实路径：

- M1-01 可以发现 basename 为 Table 的目录；
- 物理路径写入注册表；
- 页面继续显示逻辑名 Table；
- 路径大小写差异不影响 Mock 快照读取。

### AC-M1-04 确认时冻结 HEAD

提交：

```json
{
  "source": {"endpoint_id": "KR_FIX_1_1_0"},
  "target": {"endpoint_id": "KR_FIX_1_0_0"}
}
```

验收：

- 每个端点只解析一次 HEAD；
- 响应返回具体 `resolved_revision`；
- 后续目录列举和文件读取统一使用该 Revision；
- 请求中不存在日期或手工 Revision 字段。

### AC-M1-05 Excel 全量过滤

SVN 树包含 Table 下的 `.xlsx`、`.xlsm`、`.xls`、`.csv`，以及其他目录中的 Excel：

- 只返回 Table 下递归的三种 Excel 扩展名；
- 扩展名大小写不影响筛选；
- CSV、TBX、CONFIG/TABLECSV 和其他目录被排除；
- 返回相对路径、最后修改人、修改时间、文件 Revision 和大小。

### AC-M1-06 失败处理

- 单个 Excel 读取失败：文件保留在 manifest，写入失败清单和稳定错误码，其他文件继续完成；
- 端点 URL 不可达或 Table 不存在：任务整体失败；
- 错误响应不包含凭据或内部堆栈。

### AC-M1-07 缓存与复现

- 缓存键包含仓库身份、端点 URL、规范化相对路径和冻结 Revision；
- 同一个冻结 Revision 再次读取可命中缓存；
- 分支在任务完成后继续提交，不影响本次快照复现。

### AC-M1-08 只读审计

源码和运行路径中不允许出现 SVN 写命令。M1 不解析工作簿，不生成 Diff 报告；仅可筛选文件级差异候选。


### AC-M1-09 文件级差异候选

快照返回左右端点的文件清单后：

- 相同逻辑 `Table` 相对路径且内容哈希一致的文件不进入 03 清单；
- 仅左侧存在、仅右侧存在或内容哈希不同的文件进入候选清单；
- 物理 `Table` 路径大小写或上层层级不同，不影响逻辑相对路径匹配；
- 候选清单不执行工作簿、Sheet 或单元格级 Diff，作为后续任务输入。
## 3. M2 预留验收

M2 才在 M1 二进制快照上解析工作簿和 Sheet，并提供文件级、Sheet 级和单元格级差异；M2 不改变 M1 的冻结和只读契约。
