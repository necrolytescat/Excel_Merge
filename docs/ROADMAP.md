- `m2.diff.v1` 单工作簿契约和 `m2.batch.v1` 批量任务契约；

- 正式结果页、工作簿/Sheet 导航、左右行字段对照和审阅交互；
- 开发模式 Replay 与输入完整的冻结回归夹具。

## 版本监控已交付能力

- 动态发现并模糊匹配固定 SVN 分支，创建后冻结仓库身份和复制边界；
- 按 `Asia/Shanghai` 计划点生成左开右闭日报，支持暂停、恢复、结束和遗漏补跑；
- Web 关闭后由 Windows 计划任务启动独立 Runner，不使用分钟级轮询；
- 计算最终净值并归因到最终形成字段状态的作者、Revision 和提交时间；
- 任务概览、二级任务列表、调度状态、Run、重试和受控报告入口；
- 不可变历史 JSON/HTML、原子 `latest.html`、30 天历史治理；
- Excel 式离线报告工作台、中文/稳定字段双层表头、颜色规则和移动布局； 
- 正式增量回放引擎、changed paths 候选缩小、不可靠输入全量兜底和语义指纹门禁。

真实验收基线为 `r26475 -> r26514`、197 个工作簿、116 条最终净变化、0 错误。
增量引擎为 28.24 秒，对比旧引擎 147.13 秒，约 5.21 倍加速；空冷缓存的主要
瓶颈仍是 `svn cat`。

## 版本对比维护方向

后续新增或修改需求不再创建新的 M2 阶段文档，直接按模块维护：

- 页面可读性、筛选和审阅效率；
- 大工作簿、大 Sheet 和宽字段的性能与可访问性；
- 批量任务可观察性与故障诊断；
- 在不破坏现有契约的前提下扩展结果消费能力；
- 对新增真实数据兼容问题进行最小、可回归的语义加固。

入口和修改规则见 `VERSION-COMPARISON-HANDBOOK.md`。

## 稳定边界

- `source=left`、`target=right`；
- Excel/CSV 同侧同冻结 Revision；
- SVN 全链路只读；
- `m2.diff.v1` 与 `m2.batch.v1` 继续作为稳定契约；
- 正式结果页不依赖 Demo；
- 不扫描 TableCsv 猜测工作簿归属；
- 不执行 Merge、Excel 写回或 SVN 写操作。
- 版本监控固定分支创建后不可修改，Revision 只保留该分支实际相关提交；
- 报告区间始终使用逻辑截止点的 `(start, end]`，失败和补跑不改变区间；
- 结构变化 `row_key=null` 且不计入 `changed_row_count`；
- 历史完整报告保留 30 天，失败不得覆盖旧 `latest.html`；
- 增量候选和缓存只能提速，不能改变 manifest、最终净值、归因和错误隔离语义。

破坏契约的修改必须显式升版。语义变化必须先有真实或固定测试数据、差异评审和用户授权，不能通过自动更新黄金结果掩盖回归。

## 后续独立能力

以下能力未实现，若启动应单独定义范围，不反向混入现有模块：

- 分布式队列、跨节点 Worker、优先级和配额；
- 跨任务全文搜索、批量导出和通知；
- 多人审阅状态与权限；
- 多区域/多轨道聚合和合入归因；
- Excel 值级 Merge 预览、人工确认与冲突处理；
- 经过单独授权和审计后的 SVN 写回。
