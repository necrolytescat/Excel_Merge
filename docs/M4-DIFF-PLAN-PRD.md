# M4 表格计划对比 PRD

> 状态：M4 已交付  
> 日期：2026-08-12

## 1. 目标

DiffPlan 面向需要重复检查固定表格集合的游戏策划。用户从一个基准 SVN 分支的 `TABLE` 目录勾选工作簿，再选择多个目标分支，系统按基准分支对每个目标分支执行只读语义 Diff。

## 2. 已冻结产品决定

- 只使用已提交 SVN 数据，不接受本地文件或上传文件。
- 计划长期复用，保存名称、一个基准分支、1～4 个目标分支和 1～10 张 TABLE Excel 相对路径。
- 计划不固定 Revision。每次运行默认 HEAD，也允许临时选择正整数历史 Revision；启动后冻结为具体 Revision。
- 基准分支是 `source`，目标分支是 `target`，继承版本比对方向语义。
- 计划可编辑，每次运行保存不可变计划快照；更换基准分支必须清空表格选择。
- 计划使用归档和恢复，不硬删除；同一计划不允许同时存在多个活动运行。
- 结果采用“全部分支概览矩阵 + 单目标分支 M2 明细页签”。
- M4 运行历史归计划管理，不混入 M2 历史任务。
- 明细保留 30 天，计划和运行摘要长期保留。
- 到期后物理删除 gzip 明细，矩阵状态、冻结 Revision、统计、结果引用和重试关系继续保留。

## 3. 创建流程

1. 进入左侧独立导航“表格计划对比 M4”。
2. 从计划列表进入新建页。
3. 选择基准分支，服务端冻结默认 HEAD 并列出其 TABLE Excel。
4. 搜索并勾选 1～10 张表格。
5. 选择 1～4 个目标分支。
6. 可在高级区域为本次运行设置历史 Revision。
7. “仅保存”创建计划；“保存并开始”创建计划后启动首次运行。

## 4. 结果语义

运行项身份是 `workbook_path + target_endpoint_id`。哈希相同为完全相同；哈希不同后复用 `m2.diff.v1`，无业务变化为语义一致，其余为有差异、部分失败或业务失败。任一侧缺失、读取失败、编排失败和取消均独立表达，不阻断其他项。

## 5. 非目标

- 本地未提交 Excel、工作区扫描和临时上传；
- 所有分支两两比较；
- Excel Merge、SVN commit 或写回；
- 修改 `m2.batch.v1` 或创建另一套工作簿语义 Diff；
- 把 M4 运行混入 M2 历史任务页面。
